# User Scenarios
1. **Doctor finds latest report:** Dashboard search "Rahul" → open patient → Reports tab.
2. **Nurse emergency (SpO2):** Ward screen shows red EMERGENCY banner (SpO2 82%) → View Patient or Acknowledge Alert.
3. **Patient checks queue:** Home → Queue: "3 patients ahead… about 15 minutes".
4. **Receptionist reschedules:** Appointments → Reschedule → pick time → toast with Undo.
5. **Administrator checks beds:** Dashboard → "Bed occupancy by ward" chart (ICU 92%).
