# Task Analysis
**Task A – Find patient record:** Goal → type name/ID/phone in search → Enter → click card → tab. 3–4 steps.
**Task B – Book/reschedule:** Appointments → choose patient, doctor, date → choose slot (booked ones disabled) → Book → toast. Reschedule: Reschedule → pick time → done (Undo available).
**Task C – Check emergency patient:** Banner always at top of ward/doctor dashboard → View Patient (1 click).
Hierarchical decomposition keeps each task ≤ 5 steps.
